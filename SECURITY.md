# Security

This skill coordinates authorized work; neither prompts nor the registry scripts are a sandbox.
Never put API keys, credentials, authentication URLs, raw session transcripts or private project files in this repository or public issues.

For ordinary reproducible bugs, open an issue containing only a minimal synthetic example and redacted diagnostics.
For security-sensitive reports, use GitHub private vulnerability reporting if the repository has enabled it; otherwise contact the maintainer through a separately established private channel before sharing details. Do not disclose live credentials or exploit details in a public issue.

Runtime authentication, tool permissions, agent shutdown, endpoint verification and independent acceptance remain responsibilities of the deployment and supervising operator. No machine-specific security patches are distributed here.
